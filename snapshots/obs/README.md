# Sanitized OBS snapshot

This is a curated public snapshot generated by the OBS collector during
`dots sync` while OBS is closed. It contains preferences, non-secret profile
settings, encoder settings, and scene collections with sensitive-looking keys
removed.

It intentionally excludes:

- `plugin_config/obs-websocket/config.json` and its password;
- stream-service credentials and generated service definitions;
- PipeWire restore tokens;
- logs, profiler data, databases, caches, and `*.bak` files; and
- plugin-manager state.

To restore it, copy `basic/`, `global.ini`, and `user.ini` into
`~/.config/obs-studio/` while OBS is closed. Do not copy this README. Reauthorize
screen-capture sources after starting OBS.
